在 PostgreSQL 里，**函数**和**存储过程**都是把 SQL 逻辑封装到数据库里的方式，但定位不同。

## 一、共同点

- 都用 `CREATE ...` 创建。
- 函数体都可以用 `PL/pgSQL` 写，用 `$$ ... $$` 包起来。
- 都支持参数。
- 都支持 `SECURITY DEFINER` / `SECURITY INVOKER` 权限控制。
- 都能封装多步 SQL，减少应用层重复代码。

---

## 二、函数

**创建：**
```sql
CREATE FUNCTION add(a INT, b INT)
RETURNS INT AS $$
BEGIN
    RETURN a + b;
END;
$$ LANGUAGE plpgsql;
```

**调用：**
```sql
SELECT add(1, 2);  -- 返回 3
```

**特点：**
- 必须有 `RETURNS`，返回值可以是标量、表、`void`。
- 能出现在 SQL 表达式里，比如 `SELECT`、`WHERE`。
- 通常**不能**在内部执行 `COMMIT` / `ROLLBACK`。
- 适合：计算、查询、返回数据。

---

## 三、存储过程

**创建：**
```sql
CREATE PROCEDURE transfer(from_id INT, to_id INT, amount NUMERIC)
LANGUAGE plpgsql AS $$
BEGIN
    UPDATE accounts SET balance = balance - amount WHERE id = from_id;
    UPDATE accounts SET balance = balance + amount WHERE id = to_id;
    -- 这里可以 COMMIT / ROLLBACK
END;
$$;
```

**调用：**
```sql
CALL transfer(1, 2, 100);
```

**特点：**
- 没有 `RETURNS`，不通过 `RETURN` 返回值。
- 可以用 `OUT` / `INOUT` 参数把结果传出来。
- **可以**在内部控制事务（`COMMIT` / `ROLLBACK`）。
- 不能出现在 `SELECT` 里当表达式用。
- 适合：多步骤操作、批处理、需要事务控制的流程。

---

## 四、核心区别

| 维度 | 函数 | 存储过程 |
| :--- | :--- | :--- |
| 创建语句 | `CREATE FUNCTION` | `CREATE PROCEDURE` |
| 调用方式 | `SELECT func(...)` | `CALL proc(...)` |
| 返回值 | 必须有 `RETURNS` | 无 `RETURNS`，可用 `OUT` 参数 |
| 能否在 SQL 中当表达式 | 能 | 不能 |
| 事务控制 | 通常不能 `COMMIT`/`ROLLBACK` | 可以 |
| 主要用途 | 计算、查询、返回数据 | 执行操作流程、批处理 |
| PostgreSQL 支持 | 一直有 | PostgreSQL 11+ |

---

## 五、怎么选

- **要算出一个结果、查数据、在 SQL 里组合** → 用**函数**。
- **要做多步操作、批处理、需要控制事务** → 用**存储过程**。

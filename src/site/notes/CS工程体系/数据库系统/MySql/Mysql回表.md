## 例子

举个例子，假设一个表的 （id，name ,  age) 
![d4a08b24a047a07e5013c1093d80da48.png](/img/user/CS%E5%B7%A5%E7%A8%8B%E4%BD%93%E7%B3%BB/%E6%95%B0%E6%8D%AE%E5%BA%93%E7%B3%BB%E7%BB%9F/MySql/pic/d4a08b24a047a07e5013c1093d80da48.png)

创建表的时候同时有 **主键id的索引** 和 作用于 age 的**二级索引** 



你给innodb建立一个索引，innodb就会给我维护一个索引树



一个聚簇索引详细来说就是这样
```bash
                                [ 根节点 / 磁盘页 A ]
                                (假设能存 1000 个 ID)
                      +---------------------------------------+
                      | ID: 100 | ID: 500 | ID: 900 | ...     |
                      +----+---------+---------+--------------+
                           |         |         |
           +---------------+         |         +---------------+
           |                         |                         |
           v                         v                         v
    [ 非叶子节点 / 页 B ]      [ 非叶子节点 / 页 C ]      [ 非叶子节点 / 页 D ]
    +-------------------+      +-------------------+      +-------------------+
    | 100 | 200 | 300...|      | 500 | 600 | 700...|      | 900 | 950 | 990...|
    +--+----+----+------+      +--+----+----+------+      +--+----+----+------+
       |    |    |                |    |    |                |    |    |
       v    v    v                v    v    v                v    v    v
    ...  ...  ...              ...  ...  ...              ...  ...  ...
       |    |    |                |    |    |                |    |    |
       v    v    v                v    v    v                v    v    v
    [叶子节点/数据页] <-----> [叶子节点/数据页] <-----> [叶子节点/数据页]
    +-------------------+      +-------------------+      +-------------------+
    | ID:100, 张三, 18  |      | ID:500, 李四, 20  |      | ID:900, 王五, 22  |
    | ID:101, 赵六, 19  |      | ID:501, 孙七, 21  |      | ID:901, 周八, 23  |
    | ID:102, 钱九, 20  |      | ID:502, 吴十, 22  |      | ID:902, 郑一, 24  |
    | ... (存满 16KB)   |      | ... (存满 16KB)   |      | ... (存满 16KB)   |
    +-------------------+      +-------------------+      +-------------------+
          (叶子节点之间通过双向链表连接，方便范围查询)
```

## 解决回表-建立联合索引


``` sql
-- 已有表上追加
ALTER TABLE user ADD INDEX idx_age_name (age, name);
-- 或
CREATE INDEX idx_age_name ON user (age, name);

```

联合索引树长这样

```sql

                                   [ 根节点 / 目录页 ]
                      +-------------------------------------------+
                      | (18, 张三) | (35, 孙七) | (55, 王五) | ... |
                      +------+-----------+-------------+----------+
                             |           |             |
             +---------------+           |             +---------------+
             |                           |                             |
             v                           v                             v
    [ 非叶子节点 / 页 B ]        [ 非叶子节点 / 页 C ]        [ 非叶子节点 / 页 D ]
    +---------------------+      +---------------------+      +---------------------+
    | (18,张三) (19,赵六) |      | (35,孙七) (42,周八) |      | (55,王五) (63,郑一) |
    | (20,钱九) ...       |      | (48,吴十) ...       |      | (70,冯二) ...       |
    +--+------+------+----+      +--+------+------+----+      +--+------+------+----+
       |      |      |              |      |      |              |      |      |
       v      v      v              v      v      v              v      v      v
    [叶子] [叶子] [叶子]          [叶子] [叶子] [叶子]          [叶子] [叶子] [叶子]
    +---------------------+      +---------------------+      +---------------------+
    | (18,张三,100)       |      | (35,孙七,500)       |      | (55,王五,900)       |
    | (18,李四,105)       |      | (42,周八,501)       |      | (63,郑一,901)       |
    | (19,赵六,101)       |      | (48,吴十,502)       |      | (70,冯二,902)       |
    | (20,钱九,102)       |      | ...                 |      | ...                 |
    | ... (存满 16KB)     |      | ... (存满 16KB)     |      | ... (存满 16KB)     |
    +---------------------+      +---------------------+      +---------------------+
          ↑ 叶子之间双向链表连接，按 (age, name) 全局有序
```

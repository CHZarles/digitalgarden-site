# 操作系统学习主线-硬件逻辑

> **先建立硬件路径，再观察内核如何使用这些机制。**

这条主线从硬件逻辑观察操作系统。

它和 [[CS工程体系/操作系统/操作系统学习主线-软件逻辑\|操作系统学习主线-软件逻辑]] 使用同一组主题，但侧重点不同。

这条主线只展开硬件组件、硬件路径和硬件带来的影响。
软件配置和内核处理放在 [[CS工程体系/操作系统/操作系统学习主线-软件逻辑\|操作系统学习主线-软件逻辑]]。

图是跨平台的教学抽象。
图不对应某一家 CPU 或某一块主板的完整实现。
具体架构差异见设备专题和后续笔记。

## 硬件主图

主图只包含物理组件和硬件路径：

- CPU 核心
- Cache
- MMU / TLB
- 芯片内部互连
- 内存控制器
- DRAM
- I/O 根端口
- 设备控制器
- DMA
- 中断控制器
- 设备和连接链路

主图回答两个问题：

```text
硬件组件在哪里？
数据和控制请求经过什么路径？
```

软件侧的主题和路径见 [[CS工程体系/操作系统/操作系统学习主线-软件逻辑\|操作系统学习主线-软件逻辑]]。

## 每个主题的固定格式

```text
一张硬件结构图
+ 一条关键硬件路径
+ 一个业务场景例子
```

阅读每篇笔记时，先看硬件主图，再沿关键路径阅读，最后看业务场景。

业务例子只解释影响。
业务例子不补充硬件组件。

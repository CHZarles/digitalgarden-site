# 主题十：具体设备专题-硬件逻辑

本篇主侧重点：具体设备的控制器、队列、DMA 和数据路径。

软件侧见 [[CS工程体系/操作系统/具体设备专题-软件逻辑\|具体设备专题-软件逻辑]]。

先学习前九个主题，再分别学习设备的控制器、队列、DMA 和中断方式。
硬件侧重点是控制器、队列、DMA、链路和完成通知。

## 设备清单

### 磁盘和 NVMe

关注控制器队列、提交队列、完成队列、DMA、持久化和中断合并。

### 网卡

关注接收 / 发送队列、环形描述符、DMA、RSS、多队列和中断亲和性。

### GPU

关注主机内存、设备内存、命令队列、设备端内核、DMA 和异步完成通知。

### USB

关注主机控制器、端点、传输类型、设备枚举和 USB 中断传输。
USB 中断传输是 USB 传输类型。
它不是 CPU 中断。

### 虚拟化和 IOMMU

关注虚拟设备、设备直通、DMA 地址隔离和 I/O 页表。

## 硬件检查问题

1. 设备控制器位于哪条设备链路上？
2. 哪些寄存器使用 MMIO？
3. 数据由 CPU 搬运，还是由 DMA 直接读写 DRAM？
4. 设备使用哪种队列、描述符和完成通知机制？
5. 设备使用中断、轮询，还是同时使用两者报告完成事件？

平台提供多门涵盖 RAG（检索增强生成）不同深度和应用场景的课程，你可以根据当前的专业知识水平选择合适的路径：

- **入门阶段：**
    
    - **[检索增强生成 (RAG) 入门](https://apxml.com/courses/getting-started-rag)**：适合初学者，系统讲解 RAG 的核心架构、信息检索技巧、文本向量化及基础管道实现。
    - **[Kerb 工具包入门](https://apxml.com/courses/getting-started-with-llm-toolkit)**：侧重实践，学习如何使用 Kerb 工具包快速构建 RAG 系统和自主代理。
- **进阶与生产环境优化：**
    
    - **[生产环境中RAG系统的优化](https://apxml.com/courses/optimizing-rag-for-production)**：专注于生产环境，涵盖检索准确性提升、性能调优、成本管理及评估框架的构建。
    - **[大型语言模型应用高级向量检索](https://apxml.com/courses/advanced-vector-search-llms)**：深入探讨高性能语义检索技术，包括高级索引算法（如 HNSW）、混合检索（向量+关键词）及大规模部署策略。
- **专家级架构：**
    
    - **[大规模分布式检索增强生成](https://apxml.com/courses/large-scale-distributed-rag)**：针对海量数据场景，讲解分布式检索、高级多跳/智能体架构、性能工程及 MLOps 运维实践。

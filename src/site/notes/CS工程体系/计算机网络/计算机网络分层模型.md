## 物理层

数据传输单位是：比特流

硬件层面规范，怎么用光信号，电信号。表示比特流。

常见设备：网卡（里面的物理层芯片，电路） ，中继器，集线器。



## 链路层

数据的传输单位是帧：
- 定义：由比特流组成的数据块
- 自顶向下定义：网络层交给链路层一个IP数据包，链路层给他加上链路层的首部和尾部，形成帧

专业词汇
	 - Mac 地址
		 - 用于局域网内的本地传输
		 - 链路层使用MAC地址表示本地网路中的网卡
			 - 因此帧里包含
				 - 目的MAC地址
				 - 源MAC地址
				 - 数据
				 - 差错检查信息
	 - 差错检验
		 -  FCS 使用 CRC-32 算法计算得到
	 - 介质访问控制
		 - CSMA/CD
			 - 是一种争用型的介质访问控制协议
			 - CSMA/CD 协议中，LLC 帧是封装在 MAC 帧的数据单元部分进行传输的
			 - 适用于总线型网络

链路层负责的距离：
	- 主机到交换机这一跳


协议：
	- ARP 协议（Address Resolution Protocol）
		- **用于实现从 IP 地址到 MAC 地址的映射，即询问目标 IP 对应的 MAC 地址** 的一种协议。ARP 协议在 IPv4 中极其重要
	- **点对点协议（PPP，Point-to-Point Protocol）**
		- 一种在**两个网络节点之间直接建立通信链路**时使用的数据链路层协议。
			- “让两台设备通过一根线（或一条专用链路）直接对话”的规则。
		- **面向字节**：以字节为单位处理数据，不像 HDLC 那样面向位。
		- **支持多种网络层协议**：一条 PPP 链路上可以同时承载 TCP/IP、NetBEUI、NWLINK 等。
		- **可认证**：支持连接认证，防止未授权接入。

以太网： 
 - 以太网是一种链路层技术。互联网是由许多不同网络连接起来的系统。互联网中可以同时使用以太网、Wi-Fi、光纤链路和其他链路技术。



常见设备：
	- 网桥，交换机，网卡（数据链路层部分：组帧、拆帧、MAC 寻址、CRC 校验）



## 网络层

数据传输单位是 packet

包含协议 ICMP，IP

IP 层主要负责：

- 给设备分配和使用 IP 地址。
- 让数据包跨越多个网络。
- 根据目的 IP 地址进行转发。
- 把数据交给正确的上层协议。


一个ip数据包的格式
```
[IP 首部][数据部分]
```

> 数据部分可能装着 tcp段，UDP数据段，ICMP消息


IP 首部中有一个 **Protocol 协议字段**
- 它说明，IP 数据包的数据部分应该交给哪个上层协议处理。
- 常见协议号包括：
	- 1 ICMP
	- 6 TCP
	- 17 UDP

IP协议首部有一个表示TTL的字段
- TTL = Time To Live，IP 包头里的一个数字。
- 初始值通常是 64 或 128。
- **每经过一个路由器，TTL 减 1。**
- 减到 0 就丢弃，并回 ICMP 超时。

设备：
- 路由器

网络层的功能
- 路由选择
- 拥塞控制（从osi七层的角度）
	- 络层的拥塞控制，核心目标是：**当网络中某条链路或某个路由器负载过重时，防止吞吐量崩溃、延迟急剧上升，并尽量让网络恢复到高效运行状态。
	- 网络层（主要是 IP 层）本身不像 TCP 那样有端到端的滑动窗口和确认机制，所以它的拥塞控制更多依赖**路由器**和**主机配合**
	- OSI 模型的功能归类：拥塞控制可以归网络层。
	- TCP 协议的实际机制：TCP 在传输层实现端到端拥塞控制。
- 网络互联

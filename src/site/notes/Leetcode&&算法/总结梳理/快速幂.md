``` python
def fast_pow(base, n):
    if n == 0:
        return 1
    if n < 0:
        return 1 / fast_pow(base, -n)
    half = fast_pow(base, n // 2)
    if n % 2 == 0:
        return half * half
    return half * half * base
```


1. **数学：** `x^a * x^b = x^(a+b)`，所以指数可以拆开加回去
2. **折半：** 偶数 `(x^(n/2))^2`，奇数多乘一个 `x`，第一张图的链 `13→6→3→1→0`
3. **二进制：** 第二张图，`13=1101=8+4+1`，平方造出 `x^1,x^2,x^4,x^8`，为 1 的位挑出来乘

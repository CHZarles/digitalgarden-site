##  前序，中序，后序遍历

| 遍历方式   | 访问顺序      | 根节点位置    | 典型用途                  |
| :----- | :-------- | :------- | :-------------------- |
| **前序** | 根 → 左 → 右 | **最先**访问 | 复制树、序列化、打印目录结构        |
| **中序** | 左 → 根 → 右 | **中间**访问 | 二叉搜索树（BST）中获取**有序序列** |
| **后序** | 左 → 右 → 根 | **最后**访问 | 释放内存、计算表达式树、统计目录大小    |

### 前序遍历
- **顺序**：先访问根节点，然后递归遍历左子树，最后递归遍历右子树。
- **特点**：
  - 序列的第一个元素**永远是整棵树的根**。
  - 对于任意子树，其根节点也总是出现在该子树序列的最前面。
- **例子**：对于树 `A(B, C)`，前序为 `A B C`。

###  中序遍历
- **顺序**：先递归遍历左子树，然后访问根节点，最后递归遍历右子树。
- **特点**：
  - 根节点将序列分为两部分：**左边全是左子树节点，右边全是右子树节点**。
  - **最重要的性质**：对**二叉搜索树（BST）** 进行中序遍历，得到的序列一定是**升序有序**的。
- **例子**：对于树 `A(B, C)`，中序为 `B A C`。

### 后序遍历
- **顺序**：先递归遍历左子树，再递归遍历右子树，最后访问根节点。
- **特点**：
  - 序列的最后一个元素**永远是整棵树的根**。
  - 访问根节点时，其左右子树都已被处理完毕，因此适合需要**自底向上**处理的场景。
- **例子**：对于树 `A(B, C)`，后序为 `B C A`。

---

### 一个关键规律（重要）
如果已知**中序遍历**序列，再配合**前序或后序**中的任意一个，就可以**唯一确定**一棵二叉树的结构。

- **前序 + 中序**：前序找根，中序分左右。
- **后序 + 中序**：后序找根，中序分左右。
- **前序 + 后序**：**无法唯一确定**，因为无法区分只有一个子节点时，它是左孩子还是右孩子。


```python
def solve(root):
    # 全局变量：记录最终答案（如果题目需要）
    self.ans = ...
    
    # 辅助函数：可以传任意需要的参数，返回任意需要的结果
    def dfs(node, 状态参数...):
        if not node:
            return 边界返回值
        
        # 前序位置：自顶向下传递信息
        ...
        
        left = dfs(node.left, 更新后的状态...)
        right = dfs(node.right, 更新后的状态...)
        
        # 后序位置：自底向上汇总信息
        ...
        
        return 需要向上返回的值
    
    dfs(root, 初始状态...)
    return self.ans   # 或 return dfs(root, ...)
```

**注意**:

- 二叉树中每个节点的值都互不相同；
- 输入的前序遍历和中序遍历一定合法；



### 二叉树的下一个节点
给定一棵二叉树的其中一个节点，请找出中序遍历序列的下一个节点。

**注意：**

- 如果给定的节点是中序遍历序列的最后一个，则返回空节点;
- 二叉树一定不为空，且给定的节点一定不是空节点；
- 不同节点权值不同；

## 例题：424. Longest Repeating Character Replacement

目标：找最长连续子串，使它最多替换 `K` 个字符后全部相同。

```python
def solve(arr, K):
    state = {}          # 每个字符在窗口中的出现次数
    left = ans = 0

    for right in range(len(arr)):
        state[arr[right]] = state.get(arr[right], 0) + 1

        # 除最高频字符外，其余字符都要替换
        while right - left + 1 - max(state.values()) > K:
            state[arr[left]] -= 1
            left += 1

        ans = max(ans, right - left + 1)

    return ans
```

窗口合法条件：`窗口长度 - 窗口内最高频次数 <= K`。收缩时先减少 `arr[left]` 的计数，再移动 `left`；每轮用窗口长度更新答案。

```python
assert solve("AABABBA", 1) == 4
```

## 例题：438. 找到字符串中所有字母异位词

目标：找出 `s` 中所有长度为 `len(p)`、且字符频次与 `p` 完全相同的子串起点。

```python
from collections import Counter

def findAnagrams(s, p):
    need = Counter(p)
    state = Counter()
    left = 0
    ans = []

    for right, ch in enumerate(s):
        state[ch] += 1

        # 窗口长度超过 len(p)，左指针右移，保持窗口大小固定
        if right - left + 1 > len(p):
            state[s[left]] -= 1
            if state[s[left]] == 0:
                del window[s[left]]
            left += 1

        # 窗口大小正好为 len(p) 时，比较计数
        if state == need:
            ans.append(left)

    return ans
```

不变量：窗口内每种字符的出现次数都不超过 `target`；每轮只会新加入 `ch`，所以只要在 `state[ch]` 超限时收缩。窗口长度等于 `len(p)` 时，计数恰好与 `target` 相同，可以记录起点。

复杂度：`left` 和 `right` 都只向右走一次，时间 `O(len(s) + len(p))`，空间 `O(字符种类数)`。

易错点：成员测试必须写 `ch not in target`，不能写 `ch not in p`；后者会对 `p` 做线性查找，最坏退化为 `O(len(s) * len(p))`。

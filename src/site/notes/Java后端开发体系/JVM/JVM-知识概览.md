### 指令集

Java虚拟机使用的是基于栈的 **指令集架构**，操作系统使用的是 **基于寄存器的指令集** 架构，详见 [[Java-项目结构]]

``` r
6: iload_0      // 把局部变量0压入操作数栈
7: iload_1      // 把局部变量1压入操作数栈
8: iadd         // 弹出栈顶两个 int，相加，结果压栈
```


JVM 可以理解成**一台以“栈”为核心运算单元的虚拟抽象计算机**，而物理机（操作系统/CPU）则是以 “寄存器” 为核心的物理计算机。
- 这种基于栈的设计，根本目的是为了**跨平台**——因为不同CPU（x86/ARM）的寄存器数量、名称和指令集各不相同，JVM无法依赖特定寄存器。
- 而栈是内存中的一个逻辑结构，所有CPU都能实现，JVM只需定义好“压栈、弹栈、运算”这一套统一规则，字节码就能在任何平台跑起来。


### 字节码文件

正如 Linux 系统的可执行文件通常采用 ELF 格式，JVM 能够加载和执行的基本单元是 **Java 类文件（`.class`）**。

不过，`.class` 文件并不是操作系统可以直接执行的机器码。它保存的是与平台无关的 JVM 字节码，由 JVM 完成加载、验证、解释执行，并在运行过程中通过 JIT 编译器转换为本地机器码。

非重点：类文件信息，字节码信息，ASM 编程

### 类被初始化的机制

类加载在概念上类似于操作系统加载 ELF，但它不是简单的把 `.class` 文件复制进内存。

#### 类被初始化的时机

JVM 只有在首次 “主动使用” 某个类或接口的时候，会触发初始化。常见的时机有：
- 实例化需求:
	-  使用 `new` 关键字创建对象
	- 使用反射 `newInstance()` 创建对象
- 静态成员访问需求
	- 首次访问或修改类的**非编译期常量**静态字段
	- 首次调用类的静态方法
- 反射操作需求
	- `Class.forName()`（默认会初始化，因为指定了初始化参数为 `true`）
	- 通过反射获取字段、方法、构造器并调用（可能触发初始化
- 继承依赖需求
	- 初始化子类时，先初始化其父类（父类的静态成员可能被子类继承或使用）

### JVM线程的概念 && 虚拟机栈
- JVM 内部可被独立调度的基本单元
- 从 Java 代码角度，一个 java.lang.Thread 对象及其 start() 方法启动的流程对应一个JVM线程
- 从JVM实现角度，每个线程都有自己独立的：
	- **Java 虚拟机栈**：保存**局部变量**，**方法调用帧**
	- **程序计数器**：记录当前线程执行到什么指令
	- **本地方法栈**：执行 native 方法时候调用
- 在主流 HotSpot JVM 的实现中：
	- new Thread(...).start() 一般就是创建一个系统线程


所以可以看到，这个内存是服务于运行时的。


例如：某个程序运行时，栈帧的形态：
	- 函数调用的栈帧：
		- 局部变量
			- 基本数据类型，值本身
			- 对象的引用，即堆地址
		- 返回地址
		- 动态链接
		- 操作数栈  ```
		┌─────────────────┐  ← 栈顶
		│   bar() 栈帧    │
		│  ├ 局部变量表    │
		│  ├ 操作数栈      │
		│  ├ 动态链接 ─────┼──→ bar() 所属类的运行时常量池
		│  └ 返回地址      │
		├─────────────────┤
		│   foo() 栈帧    │
		│  ├ 局部变量表    │
		│  ├ 操作数栈      │
		│  ├ 动态链接 ─────┼──→ foo() 所属类的运行时常量池
		│  └ 返回地址      │
		├─────────────────┤
		│   main() 栈帧   │
		│  ├ 局部变量表    │
		│  ├ 操作数栈      │
		│  ├ 动态链接 ─────┼──→ main() 所属类的运行时常量池
		│  └ 返回地址      │
		└─────────────────┘  ← 栈底 ```

### 方法区

下面这些东西都存储在方法区
#### 类元信息-Metadata

类元信息是一个类被 JVM 加载后，保存在内存中的 “类的描述信息” ， 包括：
- 类的名称，访问修饰符，父类与接口列表
- 字段描述 （名称，类型，修饰符）
- 方法描述 （名称，参数，返回值，字节码指令，异常表）
- 注解，范型签名等信息


#### 运行时常量池

存放字面量和符号引用：
- 字面量：如字符串，final常量值，基本类型数值
- 符号引用：类，字段，方法的符号引用


#### 静态变量

属于类本身，非某个实例，特点：
- 在类初始化阶段分配空间并赋初值
- 所有实例共享，生命周期与类一致 

#### 即时编译器编译后的代码

JIT（Just-In-Time）编译器将频繁执行的**热点字节码**编译成本地机器码，缓存这些机器码可以避免重复解释执行，提升性能。  
在 HotSpot 中，这些编译后的代码通常存放在 **代码缓存（Code Cache）**，属于本地内存，逻辑上仍属于方法区范畴


### 堆

堆是整个Java应用程序共享的区域，也是整个虚拟机最大的一块内存空间，而此区域的职责就是存放和管理对象和数组
